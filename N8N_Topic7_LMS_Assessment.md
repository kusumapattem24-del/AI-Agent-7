# Topic 7 LMS Assessment Document

## Advanced Planning, Reasoning & Self-Correction – Deploy a Self-Correcting Agentic Auditor

### 1. Assessment Overview
This assessment evaluates your ability to design, build, validate, and document a self-correcting AI Agent in n8n that audits transaction records, invokes a validation tool, performs iterative self-correction, and produces standardized JSON output.

### 2. Assessment Objective
Demonstrate the ability to implement planning, reasoning, validation, self-correction, structured output parsing, and conditional routing in an end-to-end agentic workflow.

### 3. Prerequisites
- Review the Requirement Document.
- Review the Implementation Guide.
- Complete Topics 1–6.
- Active n8n instance with LLM credentials.
- GitHub account.

### 4. Assessment Tasks
1. Exercise 1 – Mock Transaction Data Setup
2. Exercise 2 – AI Agent Configuration
3. Exercise 3 – Build Validation Tool
4. Exercise 4 – Configure Structured Output Parser
5. Exercise 5 – Configure Self-Reflection
6. Exercise 6 – Validate Self-Correction
7. Exercise 7 – Test Multiple Transactions
8. Exercise 8 – Review Execution Logs
9. Exercise 9 – Build Self-Correcting Agentic Auditor
